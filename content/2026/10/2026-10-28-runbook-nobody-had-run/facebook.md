# Facebook — runbook-nobody-had-run


We were asked to automate a site failover runbook.

Version controlled. Reviewed quarterly. Signed off. What it had not been in two years was run.

It had been tested by reading — which verifies exactly one thing: the document is still readable.

Automating it meant resolving every ambiguity before anything could execute. Three didn't survive.

A step named a VLAN renumbered eighteen months earlier. A person silently corrects that. A script doesn't.

Another ordered service restarts that brought the app up before its database accepted connections.

The third checked the interface came up. Not that traffic flowed.

Found by writing it, not by running it.

When did you last run yours, rather than read it?
