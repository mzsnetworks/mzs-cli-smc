# Facebook — earn-an-orchestrator

Nobody needs an orchestrator on day one. You earn one.

Orchestration doesn't create capability — it multiplies what you have. Multiply reliable tasks, get leverage. Multiply flaky ones and you've bought an expensive way to run broken scripts in the correct order.

What earns it: tasks that are idempotent (if running it twice makes anyone nervous, it isn't ready). Data you trust — a stale source of truth means the tool executes confidently against the wrong list. A rollback somebody has run. And failure you can see, step by step.

None of that requires a purchase order — just unglamorous work on what you already run.

An orchestrator doesn't make your automation mature. It reveals how mature it already was.

What's the one task you'd trust to run five hundred times tonight, unattended?
