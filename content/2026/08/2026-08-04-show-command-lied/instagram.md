# Instagram — show-command-lied

Most outages are self-inflicted. I caused one by trusting a show command. ⚡

Standby: hot. Sync: complete. Every field green.
I pulled the primary. The site went dark.

The command didn't lie — it answered the wrong question.

→ show commands report what the box believes
→ traffic reports what's real
→ verification means testing the path, not reading state

Every failover plan I write now includes actually failing over. In a window. On purpose. Before it matters. 🔁

What's the show command that burned you? 👇
