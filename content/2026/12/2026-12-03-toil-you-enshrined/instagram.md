Five things I've automated that I should have deleted instead. 🗑️

1. The report nobody read. Generated by hand for years, then automated. It ran three more years. When it broke, we waited for a complaint. None came.

2. The approval that only ever said yes. Automating it made the rubber stamp faster. Removing it meant admitting the control was theatre — a harder conversation than a script. ⚠️

3. The nightly reconciliation between two systems that disagreed. It worked beautifully, and guaranteed nobody fixed the real problem, because the symptom stopped being visible.

4. The cleanup for a process that shouldn't have made the mess. Nobody went back to the first job — the second was cheap, and the mess was gone.

5. The manual check turned into a test that checked the wrong thing — it automated what we did rather than what we meant. It ran green for a long time. ⚙️

The pattern is the same every time.

Automation lowers the cost of a task to near zero, and nothing that costs zero gets reviewed again.

The work becomes invisible rather than absent. Invisible work is permanent.

So the question isn't "can this be automated." It's "should this still happen at all."

And that gets harder afterwards — the script is evidence somebody thought it was worth doing.

What have you automated that should have been deleted?
