# Facebook — defining-what-good-means


SD-WAN did not remove the WAN engineer. It moved the hard part.

Configuring links used to be the work. That part is largely solved now.

What replaced it is a question nobody wants to answer: what does "good" mean for this application?

The policy engine enforces whatever you tell it. It needs to know the ERP tolerates latency but not loss, that voice is the reverse, that replication takes what's left. Those aren't network facts — they're business decisions about which application loses.

So the project stalls in a meeting, not a lab. Every application owner says "mine is critical," which is the same as nobody answering.

Who is allowed to say which application loses?
