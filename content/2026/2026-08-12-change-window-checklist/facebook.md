# Facebook — change-window-checklist

The 2am rollback isn't bad luck. It's a checklist that was never written.

Four lines kill those nights:

1. Pre-checks captured — state snapshotted before anything changes
2. Blast radius written down — "not sure" means not ready
3. A back-out that's been run — an untested rollback is a theory
4. One named decision-maker — criteria set at 2pm, not vibes at 2am

The checklist moves every decision out of the window. The window is for execution; the thinking happens in daylight.

Well-run changes look boring. Boring is the achievement.

Plan at 2pm. Execute at 2am. Never think at 2am.
